# 钢铁前线：卡牌对决

原创军事题材卡牌对战原型：单机 AI 对战、自定义整张卡牌贴图、卡牌效果编辑、本机自动保存、JSON 卡组导入/导出。

## 出战卡组和战斗队列

在「卡牌工坊」可新建、选择、重命名和删除多个已保存卡组；每个卡组独立保存 8 张出战卡。点击卡位再点卡牌可直接替换，已做好的卡组也能继续编辑。卡牌可以重复选择，加入顺序就是战斗顺序。商城购买的单卡会直接加入卡牌库，可编入任意卡组。战斗时手牌区域一次展示 4 张；打出一张后，从选定的 8 张出战卡中随机抽一张补位，卡池无限循环，不会抽完。新一局使用当前选定的 8 张。

卡牌工坊要求新建卡牌上传贴图。Android 版本通过系统图片选择器选取贴图；图片会压缩后用作整张卡面，手牌和战场上的单位都以完整卡牌显示；卡面不使用 emoji 图标。步兵班、空袭、中型坦克、反坦克导弹、轻型侦察车和重型坦克采用你提供的贴图，并作为独立 Android 资源打包。轻型侦察车与步兵班互换了费用、攻击、生命、穿甲和防御数值。

单位卡还可以自定义攻击、生命、穿甲和防御。单位攻击时，穿甲必须高于目标防御才能造成伤害；伤害按“攻击 ×（穿甲 − 目标防御）÷ 10”计算。单位交战会逐步显示攻击、受伤、反击和反击伤害；打出当前展示的 4 张中的一张后，会从 8 张出战卡池中随机抽 1 张补位，卡池无限循环。


## 效果、商城与经济系统

商城商品可以在「管理商城商品」中新增、编辑、删除，分别设置名称、价格、说明、商品贴图和仓库效果；也可以创建单卡商品，设置价格、说明、贴图并选择出售的单张卡牌；购买后卡牌副本直接加入卡牌库，不会作为整套卡组出售。已下架的补给商品仍可从仓库使用。卡牌工坊可为额外效果设置数值，支持总部伤害/恢复、群体伤害、抽牌、部署恢复，以及己方攻击/防御提升、敌方攻击/防御削弱。攻防效果持续至本场战斗结束。

商城界面参考了你提供的金属边框和武器目录样式。新存档有 1000 GP；每日补给可领 100 GP，胜利获得 150 GP，失败获得 40 GP。商城商品会存入仓库：随机卡包可开出卡牌库副本，医疗箱可恢复总部生命，攻击/防御组件可强化本场己方单位。抽奖每次消耗 180 GP，奖品概率在抽奖页显示。

## GitHub Actions 云端构建 APK

1. 把本目录内的全部内容上传到 GitHub 仓库根目录（不要只上传 `app/`）。
2. 推送到 `main` 或 `master` 分支，或在仓库 **Actions → Build Android APK → Run workflow** 手动启动。
3. 构建完成后，在运行详情页下载 `steel-front-apk` artifact，解压即可得到 `app-debug.apk`。

工作流会安装 Temurin JDK 17、Gradle 8.9、Android SDK 35，创建 Gradle Wrapper 并执行 `./gradlew --no-daemon assembleDebug`。APK artifact 保留 30 天。

## 本地构建

需要 Android Studio、JDK 17 和 Android SDK 35。用 Android Studio 打开本目录，等待 Gradle 同步后选择 **Build → Build Bundle(s) / APK(s) → Build APK(s)**。
